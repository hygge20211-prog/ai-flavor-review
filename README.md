# AI 味设计评审 Skill

**v0.2.1｜评分标准 v0.2｜MIT License**

上传一张产品界面、设计稿或内容封面截图，获得 AI 味暂评分、具体问题、影响与修改建议。也可以比较两个版本，查看差距主要在哪里。

评审覆盖表达贡献、注意力分配、构成关系与视觉平衡，包括图文重复、信息层级、同构、对齐、边距、缩进和重心。分数表示这套框架下的问题程度，不判断作品是否由 AI 生成，也不默认极简风格更好。

你需要一个支持看图、读取随包说明文件的 AI 助手。无需为本 Skill 单独配置 API 密钥或额外服务。

## 快速开始

### 1. 在 Codex 中安装

把下面这段话复制给 Codex：

```text
请使用 $skill-installer 安装 GitHub 仓库
hygge20211-prog/ai-flavor-review 根目录的 Skill。

仓库内路径为 .，安装名为 ai-flavor-review。
请保留全部 references 文件和案例图片。
```

安装成功后，在下一轮对话使用。如果没有识别到新技能，重启 Codex。[OpenAI 官方安装说明](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)

**如果你从小红书的 Skill 组件获取本技能：** 复制平台提供的安装口令，发给支持 Skill 的 AI 助手，按提示完成安装。之后上传截图并选择“AI 味设计评审”；具体调用语法以所用助手为准，Codex 中可使用 `$ai-flavor-review`。

### 2. 上传截图并开始评审

附上待评截图，把任务和状态换成你自己的情况，再发送：

```text
请使用 $ai-flavor-review 评估这张界面的 AI 味。

用户任务：查看本月预算剩余。
当前状态：正常使用。
评估范围：截图中的完整首屏。

请给出 0–10 的暂评分、具体证据、影响、修改方向和待判项。
```

只有截图也可以开始：请它先做视觉暂评，标明任务假设与待判项。缺少背景的信息不会自动算作没有问题。

### 比较两个版本

附上两张图，并说明它们各自的用途：

```text
请使用 $ai-flavor-review 比较这两个页面。
页面一用于浏览当月流水，页面二用于管理周期计划。
分别评分，并说明哪些分差有证据、哪些来自任务差异。
```

## 怎么看评审结果

- **0–10 暂评分：** 分数越高，表示本框架下的问题越明显。这是主观粗分，不是 AI 生成概率，也不宜作为客观排名。
- **具体证据与影响：** 说明哪句话、哪个元素或哪种关系造成了什么负担；同一原因不会跨维度重复扣分。
- **修改方向：** 针对具体问题提出可继续调整的办法，同时指出值得保留的关系。
- **待判项：** 将缺少的任务、业务口径或交互状态列出来，不把推测写成已经验证的事实。

案例分数用于对照，不是固定答案。页面任务、显示范围或状态不同，判断可能变化；优先看证据和理由。

## 其他安装与使用方式

### 手动安装到 Codex

1. 点击本仓库的 **Code → Download ZIP**，或直接[下载 ZIP](https://github.com/hygge20211-prog/ai-flavor-review/archive/refs/heads/main.zip)。
2. 解压后，将包含 `SKILL.md` 的这一层文件夹命名为 `ai-flavor-review`，保留其中全部文件和子目录。
3. 所有项目都要使用时，放入 `~/.agents/skills/ai-flavor-review/`；只给一个项目使用时，放入该项目的 `.agents/skills/ai-flavor-review/`。`~` 代表用户主目录。
4. 确认 `SKILL.md` 直接位于上述目录中，再在下一轮对话使用 `$ai-flavor-review`。若未被识别，重启 Codex。

其他支持 Agent Skills 的工具，按自身说明安装完整文件夹。[OpenAI 官方技能目录说明](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)

### 只用 ChatGPT 网页版

上面的本地目录步骤面向 Codex。只把 GitHub 链接贴进聊天，不代表已安装这个 Skill。

如果当前对话支持文件和图片上传，可以先下载仓库，将 `SKILL.md`、`references/rubric.md`、`references/calibration-cases.md`、`references/output-format.md` 作为评审说明上传，并附上待评截图；需要对照案例时也提供相应案例图片。请模型先读取这些说明，再进行评审。这是按文档使用的方式，不等同于持久安装。

## 适用范围与限制

截图只能支持当前可见范围的判断；隐藏状态、实际点击反馈、统计口径等需要补充材料。裁切图不能直接支持全页重心结论。当前评分仍在案例校准阶段，未完成大样本、跨模型的一致性验证。

圆角、渐变、插画、emoji、信息密度和组件一致性本身不扣分；对齐和边距也结合角色、层级及视觉效果判断。
