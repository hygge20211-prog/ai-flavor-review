# 评分标准 v0.2

## 评什么

“AI 味”在本框架中是一个主观评审入口，指向不必要表达、强调及构成失配带来的阅读感受。评分帮助定位问题和比较改版，不是来源鉴定、生成概率、设计总排名，也不覆盖所有审美感受。

评分单位是：**页面 × 用户任务 × 当前状态 × 显示范围**。任务包括阅读、理解、选择、操作和感受品牌；允许有依据的并列目标。

| 输入 | 作用与不足时的处理 |
|---|---|
| 清晰截图、页面或画面序列；完整/局部范围 | 定位证据。只看裁切图不能断言全页失衡；能查看整图时回到整体检查。 |
| 用户、主要任务、页面职责 | 支持必要性与优先级判断。可以提出显式假设，不能当成用户确认的事实。 |
| 正常、首次、空数据、异常等状态 | 决定说明和状态提示是否必要。未提供不默认为正常或无问题。 |
| 涉及判断的业务口径、品牌目标、限制 | 按需补充；不要求先提供完整需求文档。 |
| 必要交互、相邻页面、真实数据 | 支持反馈、图表选中、列表联动和统计判断。截图不能证明行为。 |

用图能力不足、文字不可辨或关键区域不可见时，明确评审范围，必要时暂不给整体分。截图中的编辑选框、标注、原型工具标签等先辨认角色，不能自动当作成稿元素。

## A．表达贡献与累积负担

核心问题：承担说明、引导或辨认的内容，读过后增加了什么理解？

看文字、图标、数字、标签之间的新增贡献，不只逐句检查。类型标题旁又安排同义图标，范围词多次重复，各自再占一行，可能形成累积负担。不要凭“元素都解释得通”就停止检查组合。

| 可观察证据 | 影响与修改方向 |
|---|---|
| 同一作用被标题、说明、同义图标反复表达 | 增加扫描节点；保留贡献明确的表达，合并、压缩或调整其位置。 |
| 关键标签、操作文案只有泛化口号，没有对象或动作 | 难以确认内容或去向；用实际对象、状态、动作替换。 |
| 情境、题干、选项说明反复描述同一安排 | 阅读量上升，区分条件增加有限；把新增条件合入标题，保留有用情境。 |

正向和边界：

- “有三笔未同步”提供状态，不能按额外文字扣分。
- 总数与分类数可以并存；整体概况与构成不是天然重复。
- “买本书”相较“读本书”增加消费条件；“没有明显偏向”相较“两种都挺好”明确偏好关系。压缩时保留这些新增含义。
- 图标可帮助辨认，文字可提供无障碍或新手说明。装饰不必逐个增加数据。品牌、情绪、测试情境的职责需结合目的判断。
- “可以搬到其他产品”“删掉还能读懂”只是检查线索，不足以单独证明无效。

## B．注意力分配

核心问题：已知任务需要的信息和操作，是否获得相称的显著程度？

观察字号、字重、位置、面积、明暗、颜色、留白与重复强调如何共同分配注意力。记录具体元素之间的相对关系，不能以“颜色多”“卡片多”替代证据。

- 预算剩余是否应优先，取决于查看预算还是快速记账等任务。
- 9 笔计划是否应最大，取决于管理计划数量还是判断未来现金流等职责。任务未知时不把另一种任务强加给页面。
- 重要性不同却完全同级，或次要信息持续抢先，可构成问题；给出应先看什么以及依据。
- 多任务监控、同等重要的数据比较可以并列，不强迫唯一焦点或巨大的主按钮。
- 选中态的底色、描边、单选标记可以共同表达状态，不能按语义重复简单扣分。

## C．构成关系与视觉平衡

### 内容对应

确认谁属于谁、谁与谁比较、哪个值对应哪个对象、图例与图形如何对应。图表口径不明与图表交互未知分开记录。统一容器不能替代关系说明。

### 跨层级同构

检查一级、二级、最小信息单元及图标是否共享可辨的构成规律：

- 主体、数值、辅助说明、图标的相对位置是否可复用。
- 同类关系是否稳定，不同职责的差异是否有内容依据。
- 图文间距、信息组内外的间距，是否帮助识别层级。
- 形式相似的位置是否承担相近的信息职责。

同构程度不要求全页越高越好。一个图表与一行流水可以采用不同结构；相似摘要则可以保持同一种读法。不要把统一外壳当作充分条件，也不要为差异而打破稳定关系。

### 对齐

先识别页面、容器和记录内部各自的基准，再判断偏离。看同层级、同职责的信息是否无理由改变阅读起点；标题、图标、箭头作为整组检查。

内容卡片中的月份标题可沿用内容标题的左侧基准；页顶月份切换也可居中。两页顶部月份都居中，不能拿该事实作为两页分差。对齐选择按具体角色和既有规则判断，不把某个案例升级为“所有日期必须居左”。

### 边距、留白与缩进

分别检查：页面外边距、卡片内边距、图文间距、分组间距、嵌套缩进。不要把它们混为同一种空白。

例如，卡片内部图标到左缘与金额到右缘的空隙，是卡内关系；时间线到整张卡片的缩进，是卡外关系。时间线存在不能解释卡内留白不均，也不能自动证明外部缩进幅度合适。

相同职责的重复单元应有稳定节奏。数值相同不是充分条件；图标留白、字形及光学修正可能需要差异。从截图判断可见效果，不臆造原稿尺寸。

### 视觉平衡

把文字、图标、色块、底板、图表、悬浮元素的重量一起看，检查整组与整页的重心、留白和节奏。连续浅灰卡片偏置一侧、再叠加同侧深色按钮，可能共同加重该侧。

有功能理由的缩进仍要检查结果。按钮右缘沿用卡片右缘、左缘额外内缩，会形成向右偏的深色重量；先观察这套基准和效果，再提同宽、居中或明确分组等有依据的方案。不要把所有元素几何居中作为目标。

## 记录证据与未知

| 类型 | 写法 |
|---|---|
| 已见事实 | “金额、说明、明细标题从左侧起读；日历月份与箭头作为一组放在中部。” |
| 用户背景 | “用户说明此页主要用于检查预算。” |
| 本次假设 | “未给任务，先按查看计划支出与后续账单评视觉呈现。” |
| 解释/推测 | “这一排列可能增加跨区寻找对应项的负担。” |
| 待判 | “不知道选中日期是否筛选列表，需要交互状态。” |

有依据的设计判断不要求先做用户实验，但不能将推测写成实验结论。不要声称用户耗时、转化下降、触达困难已被测量。统计总额与最大单笔看似冲突时，先确认退款、净额和时间口径。

## 去重与问题粒度

先形成可定位的问题，再选一个主维度。去重时看根因、对象、影响与修复是否独立。

| 现象 | 主归属与处理 |
|---|---|
| 同义图标重复标题，并单独占一行，因而增加扫描节点 | A；占位和注意力影响写在同一条中，不再给 B/C 重复计入。 |
| 时间线缩进过大，使整列卡片向右，右侧视觉重量加重 | C；缩进、外边距与重心是同一问题链。 |
| 卡片内部留白不均，且整张卡片在页面内偏右 | 分别观察内、外关系。修复一个仍保留另一个时可独立记录，整体档位仍不按条数相加。 |
| 同侧悬浮按钮既加重右侧重量，又遮住记录 | 重量作为关联影响说明；修好缩进或重心后仍存在的遮挡，可独立归 C，不因同一按钮再跨 B/C 重复计算。 |
| 另一模块仍独立压过主任务，修复冗余文字后也存在 | 可单列 B，须提供独立对象或关系证据。 |

不确定是否同一问题时先合并，保留其他影响作为关联说明。

## 整体评分

整体为 0–10 的主观粗档，分高表示这套框架下的问题重。它不是等距测量、百分比或维度算术和；不设已验证的权重或来源阈值。

| 档位 | 暂定锚点 |
|---|---|
| 0 | 在材料足够支持的当前范围内，未见明确问题；不是未检查项的默认值。 |
| 1–2，偏轻 | 内容与构成基本成立，局部轻微负担，关键阅读关系清楚。 |
| 3–5，中等 | 可定位的表达或构成问题较明显，或几个关联问题累积；主要内容仍可辨认。 |
| 6–8，较重 | 问题在多个关键区域反复出现，明显妨碍核心内容的理解、重点或对应关系。 |
| 9–10，很重 | 大部分关键区域的意义、优先级或关系都难以可靠辨明；当前案例尚不足以校准这一级，谨慎使用。 |

A/B/C 可标“未见明确问题、局部问题、明显问题、待判”，用于诊断，不单独相加成总分。兼顾影响范围、任务关键性及能否从现有线索恢复理解；避免小数制造精确感。

比较与修订：同类角色采用同一检查尺度，任务不同先说明差异。分数优先与相近校准案例比较。新增证据后重新评全页，说明为何改变；不能因用户说“AI 做的”、换了一种风格或新增一条标准就机械涨分。

## 后续校准

选一小批任务明确、风格和密度多样的页面，由不同评审者独立记录证据、归属、档位和待判项；暂时隐藏来源。先比较问题是否存在，再比较归属和严重程度。补全背景、修订规则、保留合理分歧，不能只取平均数。

可用对照检查：压缩重复表达后 A 是否改善；只换圆角/渐变而关系不变时分数是否保持；补必要状态说明后是否允许页面更密却更好；同图换任务时 B 是否按依据变化。另记整体直觉，发现框架覆盖不足时再研究，不把评分者训练成只认可现有三维。
